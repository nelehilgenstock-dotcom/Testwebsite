Machine Learning und seine Unterkategorien

Machine Learning ist ein Teilbereich der KI, bei dem Systeme aus Daten lernen. Man unterscheidet drei zentrale Lernarten:


Überwachtes Lernen

Das Modell lernt anhand von gelabelten Daten. Beispiele: Klassifikation von E-Mails (Spam/Nicht-Spam).

Unüberwachtes Lernen

Das System erkennt Muster ohne vorgegebene Labels. Beispiele: Kundensegmentierung.

Bestärkendes Lernen

Ein Agent lernt durch Belohnung und Bestrafung. Beispiele: Spiel-KI oder Robotik.



Deep Learning

Spezielle Form des Machine Learning mit tiefen neuronalen Netzen. Besonders geeignet für Bilderkennung, Sprache und komplexe Muster.
